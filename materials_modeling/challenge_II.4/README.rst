Si electronic properties
========================

The Si ASE script was modified to test different values of Gaussian broadening ( *degauss* ). 
The original script used a *degauss* value of 0.01 (found inside ``class_exercise`` folder).
For the modified scripts, *degauss* values of 0.002 and 0.05 were considered (``electronic_properties_si_002`` & ``electronic_properties_si_050`` , respectively).

The DOS results were then plotted in the same figure, for comparison purposes (``degauss_challenge_comparison.png``)
